# 🍔 برجر حاتم — موقع مطعم برجر تجريبي (جدة)

> ⚠️ **مشروع تدريبي افتراضي فقط** — الاسم والشعار والألوان والأسعار والموقع كلها تجريبية وغير نهائية، وليست إطلاقًا حقيقيًا.

موقع عربي (RTL) متجاوب لمطعم برجر سعودي اقتصادي بفكرة مختلفة:
**بدل السندويتش الفردي → صحن مشاركة**: قطعة لحم كبيرة في النص + خبز + مكونات، وكل شخص يكوّن لقمته بنفسه.

## 📁 الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية: Hero + التجربة + وجبة جماعية + مكونات + اختر مزاجك + أسعار + آراء + الموقع + CTA |
| `menu.html` | القائمة: فردية / مشاركة / إضافات / صوصات / مشروبات + سلة تجريبية |
| `order.html` | كوّن وجبتك: الحجم / الخبز / الصوص / الإضافات / الحدة / الأشخاص + سعر تفاعلي |

## ▶️ التشغيل

بدون أي build — افتح مباشرة:

```powershell
start index.html
```

أو بسيرفر محلي:

```powershell
npx serve .
# أو
python -m http.server 8080
```

ثم افتح `http://localhost:8080`
